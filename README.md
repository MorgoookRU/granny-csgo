# Granny Tactical Lab — итерация 6

Тестовая Android-сборка мода Granny с механиками, вдохновлёнными CS:GO.
Создана с помощью AI. Целевое устройство: Samsung Galaxy S23+, Android 16,
ARM64. Основа: Granny 1.8.12, Unity 6000.0.68f1, IL2CPP metadata 31.

## APK

**Текущая версия — Granny Tactical Lab · 6.**
[Скачать итерацию 6](https://github.com/MorgoookRU/granny-csgo/releases/download/iteration-06/granny-tactical-iteration-06.apk).
Установить поверх пятой версии. Игра и мод запускаются автоматически.
При начале игры включены оружие и четыре бота; стартовое оружие — AK-47.

По просьбе пользователя Android-панель убрана. Управление оружием,
магазин, HP/патроны и прицел создаются внутри Canvas игровой сцены Unity.
В магазине четыре страницы, по 12 позиций, всего 42 предмета.
Оригинальные управление движением и взаимодействие Granny остаются игровыми.

Кнопки игрового интерфейса: **FIRE**, **R**, **AIM**, **JUMP**, **NEXT**, **BUY**.
**BUY** открывает магазин, **CLOSE** закрывает; стрелки переключают страницы.
Покупка новой позиции расходует деньги, нажатие на купленную выбирает её.
Противники включены без отдельного выбора режима.

Пользователь подтвердил установку пятой APK и исправление поиска ресурсов.
После включения мода возник SIGSEGV: при включении оружия в игре и при покупке
в режиме с ботами. Точная нативная причина ещё не установлена.
В шестой добавлены проверки живых Unity объектов, соответствия типов
и размеров boxed values, закрепление массивов модели, подготовка камеры
перед созданием сцены и отсрочка удаления старой модели до создания новой.
Этапы и имена вызовов записываются в локальный журнал.

После вылета доступен экран **Копировать отчёт**. Также удержать иконку
приложения и выбрать **Отчёт**. Нативный tombstone Android теперь разбирается
в текст: сигнал, адрес, поток падения, стек и build IDs. Журнал показывает
последние записи, а не только старое начало файла. Отчёты не отправляются сами.

Прежние package и подпись; versionCode 97. Таблица ресурсов побайтно
сохранена из установленной третьей версии; семь Unity resource lookups
используют fallback к исходному package. Unity работает в процессе `:game`.
Application минимальный, автоматические providers SDK отключены.
Новый интерфейс и исправления нативного падения на телефоне пока не подтверждены.
Идентификатор: `com.modlab.grannycsgo`, архитектура ARM64.

## Что включено в код этой итерации

- 34 огнестрельных оружия, нож, Zeus и шесть видов гранат.
- Боезапас, перезарядка, автоматический/одиночный огонь, дробь.
- Отдача камеры, разброс при движении, прыжке и приседании.
- Прицелы для оружия с оптикой, очереди для Glock/FAMAS.
- Магазин: $16000 на старте, покупки, броня и награда за убийства.
- Четыре противника с навигацией, проверкой видимости, стрельбой,
  здоровьем, бронёй, попаданиями в голову и возрождением.
- Взрывные, световые, дымовые, зажигательные и шумовые гранаты.
- Простой HUD, переключение оружия и доступный журнал диагностики.

Модели оружия и противников пока состоят из простых геометрических деталей.
Звуки синтезированы для этой сборки. Баланс и паттерны отдачи приблизительные.
Дым пока отображается простой геометрией. У ботов базовое поведение;
командная тактика, перезарядка ботов, раунды и установка бомбы не реализованы.
Полная игровая работоспособность перечисленных механизмов требует проверки.

## Как проверить на телефоне

1. Установить поверх прежней версии и открыть приложение: мод включится сам.
2. Начать с Practice, проверить, видны ли AK-47 и новый игровой HUD.
3. Проверить FIRE/R/AIM при одновременном движении и повороте камеры.
4. Открыть BUY, купить другое оружие, выбрать купленное, сменить страницу.
5. Проверить ботов: движение, стрельбу и попадания.
6. При вылете скопировать полный отчёт, включая NATIVE TOMBSTONE и последний STAGE.

## GitHub и доставка APK

Архивная первая APK (сообщён вылет при старте на S23+):
[скачать granny-tactical-iteration-01.apk](https://github.com/MorgoookRU/granny-csgo/releases/download/iteration-01/granny-tactical-iteration-01.apk).
В [Release iteration-01](https://github.com/MorgoookRU/granny-csgo/releases/tag/iteration-01)
также опубликована контрольная сумма SHA-256.

Исходники сохраняются в Git, APK прикрепляется к Release отдельным файлом:
он больше лимита обычного файла GitHub. Публичная доставка выбрана пользователем.
Ключ подписи остаётся вне репозитория. Для повторной публикации:

```sh
python3 scripts/publish_release.py --repo MorgoookRU/granny-csgo --allow-public --via-actions
```

Прямая загрузка бинарных файлов через HTTP-прокси облака возвращала
`Bad Content-Length` даже для файла контрольной суммы. Поэтому APK передан
частями через Git, восстановлен и проверен в GitHub Actions, затем прикреплён
к Release как один установочный файл. Ключ подписи и авторизация не загружались.
Для другой итерации указать `--iteration iteration-06`; метаданные и описание
берутся из `releases/iteration-06.json` и `releases/iteration-06.md`.

## Локальная сборка

Исходники мода находятся в этой папке. Игровые файлы, дампы,
ключ тестовой подписи и APK находятся отдельно в `/workspace/granny-lab/`.
Все итерации должны подписываться одним сохранённым ключом.

- `scripts/generate.py <generated>`: таблицы оружия и собственные звуки.
- CMake + Android NDK r27c: `arm64-v8a`, API 24, `c++_static`.
- `SHADOWHOOK_SOURCE`: локальный checkout ByteDance ShadowHook 2.0.1.
- `GENERATED_SOURCE`: папка с созданным `weapons_generated.h`.
- `scripts/package_apk.py --lab <lab>`: Java/D8, вставка загрузчика,
  объединение исходной игры с ARM64-библиотеками, упаковка и подпись.
- `checks/combat_check.c`: проверки собственного боевого ядра на Linux.

Библиотека ShadowHook: https://github.com/bytedance/android-inline-hook,
MIT; лицензии ShadowHook/xDL/LSS включены в APK в
`assets/granny_csgo/NOTICE.txt`.
