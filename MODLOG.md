# Granny × CS:GO — журнал разработки

## Цель

Модификация первой Granny для Android, с упором на механики CS:GO:
весь арсенал, отдача и разброс, перезарядка и боезапас, движение,
покупка оружия и экономика, враги под управлением ботов.
Пользователь хочет попробовать результат на телефоне без доступа к ПК.

## 2026-10-03 — разведка

- Набор инструментов: `/workspace/universal-modder`, версия 0.2.0.
- Прочитаны `AGENTS.md`, `mod-any-game`, `game-recon`,
  `reverse-engineering`, `mashup-mods` и памятка Unity.
- В базе знаний нет заметок про Granny.
- Готовая памятка Unity ориентирована на ПК; пригодность Android-маршрута
  нужно установить по реальному APK.
- Официальная карточка Android: Google Play, пакет `com.dvloper.granny`.
- APK скачан с публичного адреса APKPure в
  `/workspace/granny-lab/granny-original.apk`, 183565031 байт.
  SHA-256: `b6783b0f6e934feceafc5e31214e1119f6421b6b7c3d58f3bb52e7008c5aab56`.
  Манифест подтверждает `com.dvloper.granny`, 1.8.12, versionCode 92,
  minSdk 24, targetSdk 36. Подлинность подписи относительно официальной
  установки пока не проверена.
- Заголовок `globalgamemanagers` содержит Unity `6000.0.68f1`.
  Есть `assets/bin/Data/Managed/Metadata/global-metadata.dat`,
  magic `AF 1B B1 FA`, формат IL2CPP metadata 31.
  В APK нет `lib/` и файлов `.so`; манифест объявляет
  `com.android.vending.splits.required=true`. Для анализа native-кода
  и установки нужна полная сборка с подходящими ABI split APK.
- В строках metadata найдены `EnemyAIGranny`, `grannyHitByGun`,
  `shootGun`, `shootbutton`, `shotgun`. Это только имена;
  сигнатуры и реализация методов ещё не исследованы.
- Пользователь предложил предоставить APK и ZIP. Если среди ZIP есть
  Unity-проект или исходники, их нужно исследовать до выбора маршрута.
- Есть Python, uv и Java. Нет Android SDK/NDK, adb, apktool,
  apksigner, zipalign, dotnet, эмулятора и `/dev/kvm`.
- Выполнение игры на Android и работоспособность модификации не проверены.

2. Исследовать предоставленные пользователем APK/ZIP, если они поступят.

- Упаковка проверяет targets по оригинальному ELF и script.json IL2CPP дампа.
- DiagnosticActivity больше никогда не открывает Unity автоматически;
  в launcher есть отдельная иконка «Granny — отчёт» с собственной taskAffinity.
  Можно остановить собственный :game, скопировать отчёт, повторить с модом,
  через OpenGL или явно без мода. В игре Android панели нет.
- LauncherActivity автоматически открывает мод один раз. Pending token и
  подтверждение настоящего Unity scene callback предотвращают повторение
  незавершённого автоматического запуска через launcher; для тёплого сеанса
  token сохраняется. Два игровых hooks и их ready marker не проверены на телефоне.
- Native журнал включает pid; отчёт пытается читать native tombstone и для
  reason=2/status=11, отмечает SIGSEGV даже без трассировки. VersionCode 98.
