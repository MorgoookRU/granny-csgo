# Granny × CS:GO — журнал разработки

## Цель

Модификация первой Granny для Android, с упором на механики CS:GO:
весь арсенал, отдача и разброс, перезарядка и боезапас, движение,
покупка оружия и экономика, враги под управлением ботов.
Пользователь хочет попробовать результат на телефоне без доступа к ПК.

## 2026-10-03 — разведка

- Набор инструментов: `/workspace/universal-modder`, версия 0.2.0.
- Прочитаны `AGENTS.md`, `mod-any-game`, `game-recon`,
  `reverse-engineering`, `mashup-mods` и памятка Unity.
- В базе знаний нет заметок про Granny.
- Готовая памятка Unity ориентирована на ПК; пригодность Android-маршрута
  нужно установить по реальному APK.
- Официальная карточка Android: Google Play, пакет `com.dvloper.granny`.
- APK скачан с публичного адреса APKPure в
  `/workspace/granny-lab/granny-original.apk`, 183565031 байт.
  SHA-256: `b6783b0f6e934feceafc5e31214e1119f6421b6b7c3d58f3bb52e7008c5aab56`.
  Манифест подтверждает `com.dvloper.granny`, 1.8.12, versionCode 92,
  minSdk 24, targetSdk 36. Подлинность подписи относительно официальной
  установки пока не проверена.
- Заголовок `globalgamemanagers` содержит Unity `6000.0.68f1`.
  Есть `assets/bin/Data/Managed/Metadata/global-metadata.dat`,
  magic `AF 1B B1 FA`, формат IL2CPP metadata 31.
  В APK нет `lib/` и файлов `.so`; манифест объявляет
  `com.android.vending.splits.required=true`. Для анализа native-кода
  и установки нужна полная сборка с подходящими ABI split APK.
- В строках metadata найдены `EnemyAIGranny`, `grannyHitByGun`,
  `shootGun`, `shootbutton`, `shotgun`. Это только имена;
  сигнатуры и реализация методов ещё не исследованы.
- Пользователь предложил предоставить APK и ZIP. Если среди ZIP есть
  Unity-проект или исходники, их нужно исследовать до выбора маршрута.
- Есть Python, uv и Java. Нет Android SDK/NDK, adb, apktool,
  apksigner, zipalign, dotnet, эмулятора и `/dev/kvm`.
- Выполнение игры на Android и работоспособность модификации не проверены.

## 2026-10-03 — итерация 1

- Пользователь указал Galaxy S23+, Android 16 и попросил выдавать APK
  на каждую итерацию. Сохраняется цель полного арсенала и противников-ботов.
- Полный XAPK загружен самостоятельно: 207169504 байт, SHA-256
  `b04850aea69047be06ca41439941bf35db5dd5d37fbbf347819a6b4cc806699d`.
  В составе base APK и `config.arm64_v8a.apk` с оригинальными
  `libil2cpp.so`, `libunity.so`, `libmain.so` и AppLovin crash reporter.
- Il2CppDumper 6.7.46 + .NET 8 извлекли metadata/сигнатуры.
  Дамп сохранён отдельно в папке инструментов; интерактивный `ReadKey`
  упал после успешного создания выходных файлов.
- Найдены реальные классы `FPSControllerNEW`, `shootGun`, `EnemyAIGranny`.
  Игрок обновляется через `FPSControllerNEW.FixedUpdate`;
  доступны поля `character`, `velocity`, `PlayerIsGrounded`, `playerCrouch`,
  `forwardSpeed`, `backwardSpeed`, `sidestepSpeed`, `granny`.
- Android-маршрут: собственный JNI-модуль, динамический поиск IL2CPP API,
  подключение к FixedUpdate, Unity runtime-invoke на игровом потоке,
  собственный Android HUD. Адреса игровых методов в исходники не зашиты.
- Dobby текущей и более старой версии не собрался из-за несовместимого
  ARM64 assembler и рассогласованных Linux исходников. После повторений
  маршрут изменён на ShadowHook 2.0.1, commit
  `854c775c2c3676e57a0f383597ebf420b5204161`.
- Для сборки ShadowHook с NDK r27c потребовался флаг linker
  `--undefined-version`: общий version script включает символы ARM32,
  отсутствующие в сборке ARM64. Библиотеки и JNI-модуль собраны.
- Подготовлены собственные таблицы 42 предметов, боевое ядро,
  примитивные процедурные модели, синтезированные звуки, базовые боты,
  магазин, HUD и диагностика. Код не прошёл проверку внутри игры.
- Binary XML изменён с сохранением исходных resource/string индексов:
  отдельный package ID, название тестовой версии, снято требование split
  после добавления оригинальных ARM64-библиотек в единый APK.
- Проверки боевого ядра прошли: покупки/недостаток денег, инвентарь,
  одиночный/автоматический огонь, обычная/поштучная перезарядка,
  нож, броня, урон и ограничение денег.
- Проверены native ELF dependencies/JNI exports, binary manifest,
  подпись APK v2/v3 и zipalign. Тестовый ключ хранится вне папки мода
  и должен использоваться для дальнейших итераций.
- APK: `/workspace/granny-lab/artifacts/granny-tactical-iteration-01.apk`.
  Приложение: `com.modlab.grannycsgo`, **Granny Tactical Lab · 1**.

Следующий необходимый шаг: получить результат запуска первой APK на S23+.
Если загрузчик выдаёт ошибку, пользователь может скопировать журнал через LOG.
Запуск в игре, попадания, навигация ботов, управление и визуальная часть
не подтверждены. Полный перенос механик CS:GO не объявляется завершённым.
