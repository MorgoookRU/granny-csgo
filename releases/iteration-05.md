## Совместимость установки и исправление ресурсов Unity

Android отказал в установке итерации 4. Код отказа неизвестен; подпись
совпадает с третьей APK, а опубликованный файл имеет правильную SHA-256.

В этой версии сохранена без изменений resources.arsc третьей APK,
которая установилась. Исправление поиска ресурсов выполнено в коде Unity:
семь обращений используют fallback к исходному имени resource package.

1. Установить поверх третьей версии: тот же package/ключ, versionCode 96.
2. Нажать «Запустить игру», проверить меню и Practice без мода.
3. Если игра запускается, «ВКЛ. МОД → Оружие без ботов».
4. При падении снова открыть приложение, скопировать отчёт и прислать текст.

Установку и запуск этой версии на телефоне ещё предстоит проверить.
Независимая диагностика, отдельный процесс Unity и ручная загрузка мода
сохранены; SDK startup providers отключены.
