## Исправление обнаруженной ошибки упаковки ресурсов

Журнал с телефона показал Resources$NotFoundException (string ID 0)
при создании Unity: ресурс game_view_content_description искался под новым
именем приложения, но resources.arsc содержал старый пакет.
Исправлено имя compiled resource package; числовые ID сохранены.

1. Установить поверх итерации 3: тот же пакет/ключ, versionCode 95.
2. Нажать «Запустить игру». Если меню откроется, проверить Practice.
3. Затем «ВКЛ. МОД → Оружие без ботов».
4. При новом вылете вернуться в приложение, «Копировать отчёт», прислать текст.

Запуск этого исправления на телефоне ещё не подтверждён.
Независимая диагностика и отдельный процесс Unity сохранены.
Native-мод изначально выключен, SDK startup providers по-прежнему отключены.
