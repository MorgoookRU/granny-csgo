## Запуск после раннего SIGSEGV; отдельная иконка отчёта

Установить поверх шестой версии (package/ключ прежние, versionCode 98).
Обычная иконка автоматически запускает игру. Оружие и боты подключаются
при начале игровой сцены; управление и магазин остаются в Canvas Unity.

В шестой версии процесс :game падал и перезапускался до первого игрового
callback. Убраны ранние managed API calls во время инициализации Unity.
Bootstrap проверяет ELF build ID и методы; привязка Unity API выполняется
на игровом потоке после оригинального FixedUpdate. Исправление на Samsung
ещё не проверено; точная прежняя PC падения отсутствует в доступном отчёте.

В списке приложений появится **Granny — отчёт**: этот вход не запускает игру.
При чёрном экране открыть эту иконку → **Остановить игру** → **Копировать отчёт**.
Есть ручной повтор с модом, OpenGL и проверка запуска без мода.
Удержание обычной иконки → «Отчёт» сохранено. Незавершённый автоматический
запуск через launcher возвращает к отчёту до ручного повтора.

Нужны последние строки BOOT/STAGE/CALL и NATIVE TOMBSTONE, если Android его
предоставил. Подпись v2/v3 и выравнивание проверяются локально;
resources.arsc сохраняется из установленной третьей версии.
